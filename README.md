## Machine Learning - Delivery Time Prediction

### Objective
Predict package delivery duration using logistics
and operational features.

### Algorithms
- Linear Regression
- Random Forest Regressor

### Preprocessing
- Missing value imputation
- One-Hot Encoding
- StandardScaler
- Train-test splitting
- Scikit-learn Pipelines

### Evaluation Metrics
- MAE
- MSE
- RMSE
- R2 Score

### Model Selection
Models are compared using cross-validation
and final test-set evaluation.

### Model Artifacts
Trained preprocessing and prediction pipelines
are saved using Joblib.
